. Bicycle Rental System

A straightforward program to manage bicycle rentals and calculate costs.

Features

View available bicycles.

Rent bikes on an hourly, daily, or weekly basis.

Return bikes and automatically calculate the total bill.

How to Run

Open your terminal or code editor.

Run the bicycle rental script (e.g., python bicycle_rental.py).

Follow the on-screen menu to rent or return a bike.

2. Mushroom Program

A simple program designed to identify, classify, or track mushrooms based on their characteristics.

Features

Input mushroom traits (such as cap shape, color, and habitat).

Determine whether a mushroom is edible or poisonous.

Quick and easy-to-use interface.

How to Run

Open your terminal or code editor.

Run the mushroom script (e.g., python mushroom.py).

Enter the requested details to get the result.
