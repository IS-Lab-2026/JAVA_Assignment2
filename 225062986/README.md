# CampusDesk

CampusDesk is a simple Java desktop application.

## Features
- Bicycle Rental
- Mushroom Identifier
- Student Project Form
- Exit

## Technologies
- Java
- Java Swing

## How to Run
1. Install Java JDK.
2. Open the project in your IDE.
3. Run `CampusDesk.java`.
