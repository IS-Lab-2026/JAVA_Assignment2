# Java Swing GUI Mini-Projects

Two small desktop applications built with **Java Swing** in **NetBeans** (Form Editor / GUI Builder). Both live in the package `com.mycompany.gui` and are linked to a `WELCOME` home form through their **Cancel** buttons.

| Form | Purpose |
|------|---------|
| `BICYCLE_RENTAL` | Calculates the cost of renting a bicycle based on start and end hour |
| `MUSHROOM` | Identifies a mushroom from four yes/no questions |

---

## Requirements

- JDK 17 or newer (the code uses method references and multi-catch)
- Apache NetBeans (recommended, because the forms were generated by its GUI Builder)
- A `WELCOME.java` JFrame in the same package (`com.mycompany.gui`). Both forms open it when **Cancel** is pressed.

## Project Structure

```
com.mycompany.gui
├── WELCOME.java          (home screen, not included here)
├── BICYCLE_RENTAL.java   (rental cost calculator)
└── MUSHROOM.java         (mushroom identifier)
```

## How to Run

1. Open NetBeans and create (or open) a Java project with the package `com.mycompany.gui`.
2. Copy `BICYCLE_RENTAL.java`, `MUSHROOM.java` and `WELCOME.java` into the package.
3. Right-click the file you want to test and choose **Run File** (Shift + F6). Each form has its own `main` method.
4. Or run `WELCOME` first and navigate from there.

## 1. Bicycle Rental (`BICYCLE_RENTAL`)

### What it does
The user enters a **start time** and an **end time** (whole hours, 24-hour clock). The app charges per hour of rental and displays the total in Rwandan francs (RWF).

### Interface

| Component | Description |
|-----------|-------------|
| `txtstart` | Start hour (0 to 23) |
| `txtend` | End hour (1 to 24) |
| `txttotal` | Displays the total cost or an error message |
| `btncalculate` | Computes the cost |
| `btncancel` | Returns to the `WELCOME` form |

### Pricing rules

Each hour from `start` (inclusive) to `end` (exclusive) is priced by the hour it begins:

| Hour of day | Rate per hour |
|-------------|---------------|
| 00:00 to 06:59 and 21:00 to 23:59 | 500 RWF |
| 07:00 to 13:59 and 19:00 to 20:59 | 1,000 RWF |
| 14:00 to 18:59 | 1,500 RWF |

### Validation
The result shows `Invalid input.` when:
- start is less than 0 or greater than 23
- end is less than 1 or greater than 24
- start is greater than or equal to end

### Example

| Start | End | Calculation | Total |
|-------|-----|-------------|-------|
| 8 | 11 | 3 × 1,000 | 3000 RWF |
| 13 | 16 | 1,000 + 1,500 + 1,500 | 4000 RWF |
| 20 | 23 | 1,000 + 500 + 500 | 2000 RWF |

### Known limitation
If the fields are empty or contain non-numeric text, `Integer.parseInt` throws a `NumberFormatException`. Wrapping the parsing in a `try/catch` and showing `Invalid input.` would fix this.

## 2. Mushroom Identifier (`MUSHROOM`)

### What it does
The user answers four yes/no questions using radio buttons. When **Action** is pressed, the app uses a decision tree to display the matching mushroom name.

### Questions
1. Does your mushroom grow in a forest?
2. Does your mushroom have a convex cup?
3. Does your mushroom have a ring?
4. Does your mushroom have gills?

Each question has its own `ButtonGroup`, so only one of YES / NO can be selected per question.

### Decision tree

```
Forest?
├── YES
│   ├── Convex cup?
│   │   ├── YES → Ring?
│   │   │         ├── YES → Amanite tue-mouche
│   │   │         └── NO  → Pied bleu
│   │   └── NO  → Gills?
│   │             ├── YES → Girolle
│   │             └── NO  → Cèpe de Bordeaux
└── NO
    └── Convex cup?
        ├── YES → Agaric jaunissant
        └── NO  → Coprin chevelu
```

### Notes
- The "ring" question only matters when the mushroom grows in a forest and has a convex cup. The "gills" question only matters when it grows in a forest and has no convex cup.
- If a required question is unanswered, the result field is left unchanged.
- The unused private method `ask(...)` at the bottom of the file was auto-generated by NetBeans and can be deleted.
- In the code, "Cepe de bordeau" is a spelling slip; the correct name is **Cèpe de Bordeaux**.

## Common Features

- **Look and feel:** Nimbus (falls back to the default if unavailable).
- **Navigation:** the **Cancel** button creates a `WELCOME` form, shows it, and hides the current form.
- **Close behaviour:** `EXIT_ON_CLOSE` is set, so closing any window ends the whole application.
- **Generated code:** the `initComponents()` method and the variable declarations are managed by NetBeans. Edit the layout in the Form Editor rather than by hand.

## Possible Improvements

- Validate inputs and handle exceptions (rental form).
- Show a message when the mushroom questions are incomplete.
- Use `dispose()` instead of `setVisible(false)` to free memory when switching forms.
- Add a Reset button to both forms.
