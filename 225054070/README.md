
# Mushroom Identification and Bicycle Rental System

## 1. Project Description

This Java-based application combines two independent topics: Mushroom Identification and Bicycle Rental. It demonstrates how Java can be used to solve different problems through programming.

Both systems are implemented in Main.java, which contains the main application logic. The application also uses MushGUI.java to provide a graphical user interface (GUI), allowing users to interact with the systems through windows, buttons, and input fields.
Although the application contains two different functionalities, they are integrated into one Java project.

## Topics

**Topic 1: Mushroom Identifica8tion System**
This part focuses on identifying mushroom types based on their characteristics. It uses questions about mushroom features to help determine the mushroom type.

 **Topic 2: Bicycle Rental System**

This part focuses on bicycle rental management. It accepts rental start and end times, validates the entered information, and calculates rental charges based on the rental duration and applicable hourly rates.

## 3. Core Functionalities

**Mushroom Identification**

- Identifies mushroom types based on their characteristics.
- Uses questions about mushroom features to determine the mushroom type.

**Bicycle Rental**

- Accepts bicycle rental start and end times.
- Validates rental time inputs.
- Calculates rental charges according to the applicable hourly rates.

## Project File Structure and Responsibilities 

The project contains two main Java source files, each with a different responsibility.

-**Main.java**  — Main Application Logic
This is the main program file that combines the two systems:
-Mushroom Identification System.
-Bicycle Rental System.
It contains the program logic responsible for processing the operations of both systems.
-**MushGUI.java**  — Graphical User Interface
This file is responsible for creating the graphical interface through which users interact with the application.

It creates:

.A welcome window where users can access either system.
.A Mushroom Identification window with Yes, No, and Back buttons.
.A Bicycle Rental window with starting-time and ending-time input fields, a Check button, and an output area for the rental cost.

**Important distinction:** Main.java handles the application logic for both systems, while MushGUI.java provides the graphical interface. They work together as parts of one application.
