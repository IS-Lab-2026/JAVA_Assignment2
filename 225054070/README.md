
# Mushroom Identification and Bicycle Rental System

## 1. Project Description

This Java-based application combines two independent topics: Mushroom Identification and Bicycle Rental. It demonstrates how Java can be used to solve different problems through programming.

## Topics

**Topic 1: Mushroom Identifica8tion System**
This part focuses on identifying mushroom types based on their characteristics. It uses questions about mushroom features to help determine the mushroom type.

 **Topic 2: Bicycle Rental System**

This part focuses on bicycle rental management. It accepts rental start and end times, validates the entered information, and calculates rental charges based on the rental duration and applicable hourly rates.

## 3. Core Functionalities

**Mushroom Identification**

- Identifies mushroom types based on their characteristics.
- Uses questions about mushroom features to determine the mushroom type.

**Bicycle Rental**

- Accepts bicycle rental start and end times.
- Validates rental time inputs.
- Calculates rental charges according to the applicable hourly rates.
