Java Projects

1. Bicycle Rental System

The Bicycle Rental System is a simple program that calculates the amount a customer has to pay for renting a bicycle. The user enters the starting and ending times of the rental, and the program calculates the rental duration and the total amount to be paid.

>HOW IT WORKS 
- Accepts the starting and ending times.
- Calculates the number of hours the bicycle was rented.
- Determines the rental cost.
- Displays the total amount to be paid.
- Includes a Cancel button to return to the welcome screen.

2. Mushroom Identifier

The Mushroom Identifier is a program that helps identify different mushrooms based on the answers selected by the user.

The user answers questions by selecting Yes or No using radio buttons. After clicking the Action button, the program checks the selected answers and displays the result.

>HOW IT WORKS
- Displays questions about mushroom characteristics.
- Allows the user to select Yes or No.
- Checks the answers using conditional statements.
- Displays the result .
- Includes a Cancel button to return to the welcome screen.
