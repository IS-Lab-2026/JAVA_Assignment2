Bicycle Rental System

Description

The Bicycle Rental System is a Java application developed using Java Swing. It allows users to calculate the total bicycle rental cost based on the starting time and ending time.

Features

- Enter bicycle rental start time and end time.
- Calculate the total rental cost automatically.
- Validate entered times.
- Display the total rental cost.
- Clear or cancel the entered information.

Rental Rates

- Before 7:00: 500 RWF per hour.
- 7:00–13:00: 1,000 RWF per hour.
- 14:00–18:00: 1,500 RWF per hour.
- 19:00–20:00: 1,000 RWF per hour.
- 21:00 onwards: 500 RWF per hour.

Technologies Used

- Java
- Java Swing
- NetBeans IDE

How to Run

1. Open the project in NetBeans.
2. Run the "BICYCLERENTAL" Java class.
3. Enter the start and end times.
4. Click Calculate to see the total rental cost.

Mushroom Identification System

Description

The Mushroom Identification System is a Java application developed using Java. It helps users identify different types of mushrooms by answering simple yes/no questions about their physical characteristics and where they grow.

Features

- Ask whether the mushroom has a convex cap.
- Check whether it grows in a forest.
- Check whether it has gills or a ring.
- Identify the mushroom based on the user's answers.
- Display the identified mushroom name.

Mushroom Types

- Agaric jaunissant
- Amanite tue-mouche
- Pied bleu
- Cèpe de Bordeaux
- Coprin chevelu
- Girolle

Technologies Used

- Java
- Java Scanner
- NetBeans IDE

How to Run

1. Open the project in NetBeans.
2. Run the "MushroomIdentification" Java class.
3. Answer the questions using yes or no.
4. View the identified mushroom displayed on the screen.
