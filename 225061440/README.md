# Java Individual Lab 1 - GUI Applications

**Student Registration Number:** 225061440

## Programs Included

1. **BicycleRental.java**
   - A Java Swing GUI application that calculates the total rental fee (in RWF) for a bicycle based on integer start (0–23) and end (1–24) hours.
   - Applies hourly rates across different time intervals:
     - 0–7 and 21–24: 500 RWF/hour
     - 7–14 and 19–21: 1000 RWF/hour
     - 14–19: 1500 RWF/hour

2. **MushroomGame.java**
   - A Java Swing GUI application that identifies which of the six mushrooms (*Agaric Jaunissant*, *Amanite tue-mouche*, *Cepe de bordeaux*, *Coprin chevelu*, *Girolle*, *Pied bleu*) the user is thinking of by asking at most three Yes/No questions.
