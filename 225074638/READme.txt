**Student Registration Number:** [225074638]

## Overview
This repository folder contains my Java Swing Graphical User Interface (GUI) submission for Lab 2. The application links two welcome/navigation screens to two interactive problem-solving tools: a Bicycle Rental Cost Calculator and a Mushroom Species Classifier.

## Project Structure
* **`GUI.java`**: The main entry point of the application that launches `Welcome_1`.
* **`Welcome_1.java`**: The initial landing screen introducing the Lab 2 GUI project.
* **`Welcome_2.java`**: The navigation menu allowing the user to switch between the Bicycle Rental and Mushroom Identifier tools.
* **`Bicycle_object.java`**: Calculates total bicycle rental charges in RWF based on peak and off-peak hourly rates (`500 RWF`, `1000 RWF`, and `1500 RWF`).
* **`Mushroom_object.java`**: Uses radio button selections across four biological traits (ring, gills, convex cap, and forest habitat) to identify the matching mushroom species.

## How to Run
1. Open the project in **Apache NetBeans** (or any Java IDE supporting JDK 17+).
2. Ensure all `.java` files are inside the `com.mycompany.gui` package.
3. Run `GUI.java` to start from the first welcome window.
