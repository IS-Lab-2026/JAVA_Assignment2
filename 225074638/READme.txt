# Java GUI Lab 2 Assignment

**Registration Number:** [225074638] 
**Package:** `com.mycompany.gui`

## Overview
This repository folder contains my Java Swing Graphical User Interface (GUI) submission for Lab 2. The application opens a central Welcome menu that lets the user choose between a Bicycle Rental Cost Calculator and a Mushroom Species Classifier.

## Files Included
- `GUI.java` - Main entry point of the application that launches `Welcome`.
- `Welcome.java` & `Welcome.form` - Welcome menu window with navigation buttons for both tools.
- `Bicycle_object.java` & `Bicycle_object.form` - Calculates total bicycle rental charges in RWF based on start and end hours.
- `Mushroom_object.java` & `Mushroom_object.form` - Identifies the mushroom species based on four biological traits (ring, gills, convex cap, and forest habitat).

## How to Run
1. Open the project in **Apache NetBeans** under package `com.mycompany.gui`.
2. Right-click `GUI.java` and select **Run File**.
