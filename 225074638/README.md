# Java GUI Lab 2 Assignment

**Registration Number:** [225074638]

## About This Project
This folder contains my Java Swing GUI submission for Lab 2. The program starts with two welcome screens and lets the user open either the Bicycle Rental Calculator or the Mushroom Identifier.

## Files Included
- `GUI.java` - Starts the application by opening `Welcome_1`.
- `Welcome_1.java` - First welcome screen with a button to continue to the menu.
- `Welcome_2.java` - Second screen where the user chooses between Bicycle Rental and Mushroom Finder.
- `Bicycle_object.java` - Calculates bicycle rental cost in RWF based on start and end hours.
- `Mushroom_object.java` - Identifies the mushroom type based on 4 yes/no traits.

## How to Run
1. Open the files in Apache NetBeans under package `com.mycompany.gui`.
2. Right-click `GUI.java` and select **Run File**.
