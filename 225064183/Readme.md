# Java Projects

This repository contains two Java applications I worked on while learning and practising Java programming. Both projects use graphical interfaces built with Java Swing.

## 🚲 1. Bicycle Rental System

This program helps calculate the cost of renting a bicycle based on the starting and ending hours entered by the user.

The rental price changes depending on the time of the day:

| Time period | Price per hour |
|---|---:|
| 00:00–06:59 | 500 RWF |
| 07:00–13:59 | 1,000 RWF |
| 14:00–18:59 | 1,500 RWF |
| 19:00–20:59 | 1,000 RWF |
| 21:00–23:59 | 500 RWF |

The program checks whether the entered hours are valid, calculates the cost for each rental hour, and displays the total amount in RWF.

## 🍄 2. Mushroom Identification System

This program helps identify mushrooms by asking the user four questions about their characteristics:

- Does it have a ring?
- Does it have gills?
- Does it grow in a forest?
- Does it have a convex cap?

The user selects Yes or No using radio buttons. After clicking the Action button, the program checks the answers and displays a possible mushroom identification.

Some of the results include Amanite tue-mouche, Agaric Jaunissant, Coprin chevelu, Pied bleu, Girolle, and Cepe de bordeau.
