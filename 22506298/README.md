# JavaswingProject

A small Java Swing application with a main menu and three forms.

## Features
- **Rental System**: calculates the total price of a bicycle rental from the start and end hour.
- **Mushroom Identifier**: asks at most 3 yes/no questions and names the mushroom.
- **Student Project Form**: takes a Reg No and a Project Name.

## Files
- `MainForm.java` (the menu, run this one)
- `RentalForm.java`
- `MushroomForm.java`
- `ProjectForm.java`

## How to Run
1. Put all the files in one folder.
2. Compile: `javac *.java`
3. Run: `java MainForm`

## How to Use
- **Rental System:** enter whole numbers (start 0-23, end 1-24, start less than end) and click Calculate.
- **Mushroom Identifier:** think of one mushroom and click Yes or No.
- **Cancel:** closes the form and goes back to the menu.
- **Exit:** closes the program.
